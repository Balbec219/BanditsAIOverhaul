# Сетевой спавн V0.3

Референсы изучены локально в установленном Workshop:
- Bandits 3268487204, 42.20: BanditServerSpawner.lua и BanditCompatibility.lua.
  Сервер вызывает addZombiesInOutfit, полученный IsoZombie получает отдельные данные AI.
- ProjectALifeNPCs 3803984183, 42.20: ALifeShellAdapter.lua.
  Оболочка создаётся через createZombie, обычный AI подавляется.

BAO использует первый API и собственную маленькую реализацию. Исходники референсов
не скопированы; их код и модули не нужны для запуска BAO.

## Проверка

1. Полностью перезапустить сервер и клиент с обновлённым модом.
2. Включить admin. В Horde Manager выбрать свободную клетку рядом на своём этаже.
3. Outfit → «BAO: создать тестовую NPC-оболочку», количество 1, height offset 0.
4. Нажать Spawn. `request_sent` означает лишь отправку; сервер должен ответить `spawned`.
5. Убедиться, что объект виден. Повторный spawn должен вернуть test_npc_exists.
6. Выбрать «BAO: удалить тестового NPC», Spawn. Проверить исчезновение.
7. Повторить создание/удаление. При возможности проверить видимость вторым клиентом.

F10 использует тот же сетевой обработчик. Логи: [BAO][DebugServer] world_spawn /
world_remove и [BAO][NPCWorldClient] success=... reason=.... Без admin — admin_required.

## Границы этапа

Это одна тестовая серверная IsoZombie-оболочка. Внешность человека, собственная анимация,
patrol, сохранение/восстановление между рестартами и полноценная многопользовательская
симуляция ещё не реализованы. Оболочку удалить перед завершением теста. Проверки в Lua 5.1
проходят; успешная реальная репликация и удаление должны подтвердиться игровым тестом.
