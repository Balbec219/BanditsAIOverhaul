# Проверка админ-патруля — 2026-10-03

Обновить Workshop-мод привычным способом и полностью перезапустить сервер и клиент.
Локальная папка Workshop обновляется скриптом, загрузка в Steam отдельно.

1. На открытом участке земли создать двух NPC (можно отдельно, чтобы различать их).
2. Закрыть и снова открыть Horde Manager: список NPC собирается при открытии окна.
3. В списке Outfit выбрать BAO: bao_world_test_... — патруль к выбранной клетке.
4. Указать клетку в 5–8 клетках от NPC, на том же этаже и рядом с администратором.
   Нажать обычную кнопку Spawn. В этом режиме она отправляет команду патруля,
   нового NPC не создаёт. Count/Radius не влияют на команду.
5. Назначить другому ID другую клетку. Наблюдать движение обоих.
6. Для первого выбрать «остановить», нажать Spawn. Второй должен продолжить.
7. Для каждого выбрать «состояние в лог», нажать Spawn. В console.txt искать
   [BAO][NPCCommand]: id, state, reason, x, y.
   ARRIVED = координаты подтвердили прибытие; FAILED + navigation_stuck = нет прогресса;
   FAILED + navigation_timeout = истёк срок. request_sent/patrol_started не означают прибытие.
8. После остановки/прибытия назначить новую точку; затем удалить всех тестовых NPC.

Если персонажи стоят: через 6–10 секунд запросить состояние обоих и сохранить лог.
Не требуется повторять команду много раз. Обычный патруль — один переход к точке,
не циклический обход. Человеческая ходьба/внешность ещё не реализованы.
Скрипты не телепортируют NPC и не вызывают обновление PathFindBehavior вручную.
После создания/смерти/удаления закрыть и открыть Horde Manager для обновления списка.

Офлайн проверены права, ID, координаты, этаж, наличие пола, busy route, stop/restart,
удаление с активным AI, маршрутизация UI/сервера и независимость двух конвейеров.
Реальное движение и отображение меню в игре на момент изменения не проверены.

## Новый основной способ: F10
Создай NPC через SPAWN TEST NPC. Выбери ID в списке; REFRESH NPC обновляет его с сервера. Встань на свободную точку в 5–8 клетках, нажми TARGET: MY TILE и отойди. START PATROL назначает эту точку выбранному NPC. Через 6–10 секунд нажми NPC STATUS: результат виден в окне и console.txt. Не удаляй NPC до запроса статуса. STOP NPC останавливает выбранного NPC. Повтори со вторым NPC и другой точкой. Перед проверкой обнови мод и перезапусти сервер/клиент.
